# Video Plan: AI Coding Agents Industry Analysis

## Overview
**Duration:** 45-55 seconds
**Target:** LinkedIn & Twitter/X
**Audience:** OpenAI, Anthropic, AI/Tech professionals

---

## Storyboard & Script

### Scene 1: Hook (0-5 sec)
**Visual:** Bold text overlay on dark background
**Text on screen:** "I analyzed 1 MILLION GitHub repos"
**Narration:** "I analyzed one million GitHub repositories to answer one question..."

---

### Scene 2: The Question (5-10 sec)
**Visual:** Fade to show the 4 AI agent logos/names
**Text on screen:** "Which AI coding agent is winning each industry?"
**Narration:** "Which AI coding agent is actually winning in each industry?"

---

### Scene 3: Dashboard Reveal (10-18 sec)
**Visual:** Screen recording - zoom out to show full dashboard
**Action:** Show the overview stats (1M repos, 19 industries, 4 agents)
**Narration:** "I built a dashboard tracking Claude Code, GitHub Copilot, OpenAI Codex, and Cursor AI across 19 industries."

---

### Scene 4: Bar Race Animation (18-32 sec)
**Visual:** Screen recording of the animated bar race chart
**Action:** Play the bar race showing industries competing over time
**Narration:** "Watch how Professional Services dominates... but look at Finance and Healthcare accelerating."
**Key moment:** Pause briefly when Claude Code leads

---

### Scene 5: Key Insight - Claude Code (32-42 sec)
**Visual:** Comparison chart showing growth trajectories
**Action:** Highlight Claude Code's growth line
**Text overlay:** "Claude Code: Fastest Growth"
**Narration:** "The data shows Claude Code has the fastest growth trajectory of any agent."

---

### Scene 6: Call to Action (42-50 sec)
**Visual:** Dashboard URL + your name/handle
**Text on screen:**
- "Full dashboard: [your-url]"
- "Built with Next.js + Recharts"
- Your LinkedIn/Twitter handle
**Narration:** "Link to the full interactive dashboard in comments. All data is open source."

---

### Scene 7: End Card (50-55 sec)
**Visual:** Clean end screen
**Text:** "What industry should I analyze next?" (engagement hook)

---

## Screen Recordings Needed

- Use dark mode (looks more cinematic)
- Clean browser (no bookmarks/extensions visible)
- Record at 60fps for smooth animations

## Tools to Create the Video

### Screen Recording
- **OBS Studio** (free) - Best quality
- **Loom** (free tier) - Quick and easy
- **Windows Game Bar** (Win+G) - Built-in

### Video Editing
- **CapCut** (free) - Best for short-form, has great text animations
- **DaVinci Resolve** (free) - Professional quality
- **Canva Video** (free tier) - Simple and fast

### Text Overlays & Effects
- CapCut has built-in trending text styles
- Use bold, minimal fonts (Inter, Montserrat)

## Pro Tips for Maximum Impact

### For LinkedIn:
- Post Tuesday-Thursday, 8-10 AM your timezone
- Reply to every comment in first 2 hours
- Tag @Anthropic and @OpenAI in a follow-up comment (not main post)

### For Twitter/X:
- Post when US West Coast is waking up (8-10 AM PT)
- Quote tweet yourself with one surprising stat
- Engage with AI community accounts

### Video Tips:
- Add captions (85% of LinkedIn video is watched muted)
- First 3 seconds must hook (start with the big number)
- End with a question to drive comments
- Square (1:1) format works on both platforms
